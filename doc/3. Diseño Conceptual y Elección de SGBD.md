### Diseño Conceptual de la Base de Datos 📐

El diseño conceptual constituye el plano estructural del sistema de información previo a su desarrollo físico. Su propósito es definir con precisión la organización, las entidades esenciales y las reglas de negocio que rigen los datos del **Sistema de Constancia de Pagos de la DREA**.

Un modelado conceptual riguroso permite:
* **Planificar el alcance de los datos:** Identificar qué información clave se debe capturar y persistir.
* **Estructurar dependencias e interacciones:** Establecer vínculos claros y relaciones de cardinalidad entre entidades.
* **Optimizar el acceso y la mantenibilidad:** Garantizar un flujo transaccional eficiente y facilitar futuras extensiones o adaptaciones normativas.

Para esta fase se elaboró un modelo de alto nivel centrado en las entidades núcleo que estructuran el diseño final.

### Elección del Sistema Gestor de Base de Datos (SGBD) 🗄️

**Microsoft SQL Server** es un sistema de gestión de bases de datos relacionales (RDBMS) empresarial diseñado para almacenar, procesar y consultar grandes volúmenes de datos con altos estándares de seguridad y eficiencia (*Microsoft, 2024*).

Para el desarrollo y validación del modelo de datos de la **Dirección Regional de Educación de Ayacucho (DREA)**, se seleccionó **SQL Server Developer Edition**.

---
